# Smart Parking Management System (Spring Boot + React)

## Backend

- Java 17, Spring Boot 3
- In-memory H2 database
- Endpoints under `/api`

Run:

```bash
cd backend
mvn spring-boot:run
```

## Frontend

- React + Vite
- Uses Axios to call backend

Run:

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173 in your browser.
